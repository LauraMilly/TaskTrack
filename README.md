
📌 Task Track - EBAC Project

Task Track is a task management system designed to help users organize their schedules efficiently. This project includes a calendar, note-taking functionality, and a built-in chat feature, making it an all-in-one productivity tool. Developed as an assignment for the EBAC course, it utilizes HTML, CSS, and JavaScript for a seamless user experience.

## 📌 Technologies Used
This project was built using the following technologies:
- **HTML5** → Page structure
- **CSS3** → Styling and responsiveness
- **JavaScript** → Interactive features like calendar and chat
- **Fonts and Images** → Visual elements to enhance the UI

## 🎨 Design & Layout
The interface is designed for efficiency and ease of use, featuring an intuitive layout with a calendar for scheduling, a chat system for communication, and a notes section for quick task tracking.

## 🔹 Key Features:
✅ Responsive Layout
